이 화면은 무엇을 보여주나요?

스레드 풀 도입 전 4단계 버전에서 정상적인 GET / 요청을 처리하던 경로를 재현합니다. 현재 서버는 메인이 접속을 받아 큐에 넣고 워커가 요청을 처리합니다. 이 화면의 코드는 이전 단일 스레드 버전의 스냅샷입니다. 버튼은 학습 화면을 이동시키며 실제 서버 실행을 제어하지 않습니다.

예시는 포트 8080, 문서 루트 ./www, Connection: close를 사용합니다. 요청 헤더가 한 번에 도착하는 경우이며, 서버 코드는 나뉘어 도착하는 경우도 처리합니다. 파일은 최대 16KiB씩 읽습니다. 여기의 index.html은 한 블록에 들어갑니다.

브라우저가 HTML을 받은 뒤 CSS 등을 추가로 요청하는 과정은 별도 요청이므로 여기서는 생략합니다. L과 C는 역할을 구별하기 위한 이름입니다. 아래 코드는 의 단일 스레드 버전에서 발췌했습니다.
